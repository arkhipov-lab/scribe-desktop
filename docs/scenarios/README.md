# Scenarios

Behavioral specifications for **Scribe**.

Unlike [PRODUCT.md](../../PRODUCT.md), which describes vision and principles, scenarios describe expected behavior in concrete situations.

These documents are intended to:

- guide implementation;
- define expected UX;
- serve as acceptance criteria;
- become the basis for manual QA and future integration tests.

Authoritative smoke matrix: [TESTING.md](../../TESTING.md). Privacy rules: [SECURITY-PRIVACY.md](../../SECURITY-PRIVACY.md).
