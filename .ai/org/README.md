# AI Organization Layer

Reusable process layer for the AI development system.

This directory describes role boundaries, workflow shape, metrics, gates, and schemas that should be portable to another repository. It must avoid Scribe-specific product details except as examples or links to `.ai/product/` and `.ai/repo/`.

Use this layer when designing or auditing the AI development process itself.

| [schemas.md](schemas.md) | Current structured-state conventions and future schema targets |
